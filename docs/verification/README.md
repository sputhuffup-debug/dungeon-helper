# Alien module verification

In October 2026 every table, preset, reference list, rule card, template and tracker in `packages/module-alien` was checked against the owner's copy of *Alien: The Roleplaying Game, Core Rules, Evolved Edition* (Free League, 2025). Page references are printed folios.

Numbers, dice expressions, ranges, names and stat lines were copied exactly. Effects, descriptions and rule summaries were rewritten as short paraphrases. An automated check confirmed that no run of ten consecutive words in the module's prose matches the book, apart from data such as stat lines and name lists.
